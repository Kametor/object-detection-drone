## Project rules

- **Train/val/test splits are made at the video level, never at the frame
  level.** Consecutive frames are near-duplicates; a frame-level split
  leaks test data into training and inflates every metric. Splits are
  always made over held-out videos.
- **The gold test set is entirely human-labeled and never enters any
  pseudo-labeling step.** No model output is allowed into ground truth.
- **Every reported number must be reproducible:** fixed seed, a committed
  config file, the run command written in this README.
- **Everything must run in a standard, single-GPU Colab session.** Development
  and delivery both happen on the free T4 tier.
- **Results are never fabricated.** If a run wasn't done, that's stated
  explicitly; tables are generated by script from files under `results/`,
  never written by hand.
